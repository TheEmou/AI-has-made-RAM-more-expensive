# 双重读取 · Dual Read

> 爱让记忆变得更加珍贵  
> AI has made RAM more expensive

同一句话，两种读法。本站把这句双关做成一块可以「读取」的记忆模块：人类侧用情书的语言，硅基侧用账本的语言，写在同一种介质上——怕被忘掉的东西。

## 项目简介

主题词在拼音与字母层面擦肩而过：

| 中文 | 英文读法 | 侧写 |
|------|----------|------|
| 爱 | AI | 情感引擎 / 推理引擎 |
| 记忆 | Memory / RAM | 被反复读取的往事 / 被反复寻址的单元 |
| 珍贵 | Expensive | 无价之物 / 涨价之物 |

网站以「PCB 丝印 × 书信」为视觉方向：深色电路板基底、丝网印刷般的说明文字、铜走线分区；内容按记忆体（DIMM）的叙事拆成五个模块：

1. **双重读取** — 拆开这句双关
2. **人类档案** — 爱如何改写记忆的读取频率
3. **硅基账本** — AI 如何给内存定价
4. **同一块介质** — 可点击的 32 格存储矩阵（红=人类写入，蓝=硅基写入）
5. **统一读取** — 两种标价共用同一条害怕失去的通路

## 运行方式

纯静态站点，无构建步骤、无外部依赖（字体使用系统栈）。

**方式一：直接打开**

用浏览器打开 `index.html` 即可。

**方式二：本地静态服务器（推荐）**

```powershell
# 在本目录下执行（任选其一）
python -m http.server 8080
# 或
npx --yes serve -l 8080
```

然后访问 `http://localhost:8080`。

## 原理说明

### 设计系统

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--board` | `#1C2428` | PCB 基板底色 |
| `--silk` | `#E8DCC8` | 丝印 / 正文 |
| `--rose` | `#C96B6B` | 人类侧强调 |
| `--cell-blue` | `#5B8C9E` | 硅基侧强调 |
| `--amber` | `#D4A84B` | 过孔 / 高亮 / 英文关键词 |
| `--trace` | `#3D7A6A` | 铜走线 |

字体：中文标题用衬线（Noto Serif SC / 宋体系），正文用无衬线，硅基侧与地址信息用等宽——人格分工本身就是双关的一部分。

### 交互

- **滚动显现**：`IntersectionObserver` 触发模块入场（尊重 `prefers-reduced-motion`）。
- **记忆矩阵**：32 个单元格按行列交替「人类 / 硅基」写入类型；部分单元默认未点亮，点击后会「访问」并显示对应记忆片段。读取面板展示十六进制槽地址与片段全文。
- **键盘**：矩阵内支持方向键移动焦点。

### 无障碍与响应式

- 正文对比度按浅色文字落在深板底上设计
- 焦点环可见（`:focus-visible`）
- 375px 宽度下无横向溢出；矩阵降为 4 列
- 动画均有减弱动效分支
