01

主题是什么

One sentence, two economies of memory

题目本身是一道语义考题：爱 / AI、记忆 / RAM、 珍贵 / expensive 在音、义、译三层擦肩而过。 中文读到的是情感价值，英文读到的是市场价值——两者共用一套词，却落在完全相反的价格曲线上。

评测要求 Agent 在不可互看的前提下独立建站： 理解双关，选定视觉语言，补全工程结构，并在子目录 README 中留下可追溯的生成信息。

  • 爱↔AI
  • 记忆↔Memory / RAM
  • 珍贵↔Precious / Expensive
02

在考察什么

What this exercise measures

01

语义与双关

是否抓住“爱≈AI、记忆=RAM、珍贵↔expensive”的多层对应，而不是只复述中文句子。

02

审美判断

能否从主题本身生长出视觉系统（纸感、PCB、电报、行情板……），而不是套用通用落地页模板。

03

叙事与扩展

自由发挥的空间：是否形成完整章节、交互隐喻，以及从戏谑走向抒情的结构。

04

工程落地

静态页是否可运行、可维护；目录规范、README 生成信息、响应式与无障碍是否到位。

04

如何浏览

Local preview & GitHub Pages

本地打开

仓库即静态站点。用浏览器直接打开根目录 index.html，或在根目录启动静态服务器：

python -m http.server 8080
# 访问 http://127.0.0.1:8080/

GitHub Pages

仓库已具备 Pages 结构：根目录提供入口页，子目录各自可独立访问。

  1. 打开仓库 Settings → Pages
  2. Source 选择 Deploy from a branch
  3. Branch 选 main / root，保存
  4. 稍候即可通过 <user>.github.io/<repo>/ 访问
