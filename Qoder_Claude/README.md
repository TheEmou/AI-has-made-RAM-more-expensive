## 原理说明

- **`index.html`** — 语义化单页结构，锚点导航 + 平滑滚动。
- **`style.css`** — 深色渐变主题；内存条、AI 芯片等插画全部用 CSS 绘制（渐变、伪元素、keyframes）；`IntersectionObserver` 配合 `.reveal` 类实现滚动进场；响应式适配移动端，并尊重 `prefers-reduced-motion`。
- **`app.js`** — 无框架原生 JS：
  - 价格曲线：`<canvas>` 手绘坐标系 + 渐变折线 + 面积填充，`requestAnimationFrame` 逐点动画，devicePixelRatio 适配高清屏；
  - 换算器：滑块输入 → 按示意单价 ¥125/GB 换算为各价值单位实时渲染；
  - 记忆便签：读写 `localStorage`（键 `priceless-memories-v1`），用户内容经 HTML 转义后渲染，防 XSS；内置 3 条"网友记忆"作为示例；
  - 所有数据仅存在访问者本机，无任何网络请求。
