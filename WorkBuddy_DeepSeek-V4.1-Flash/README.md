# 爱让记忆变得更加珍贵 · AI has made RAM more expensive

一个关于「记忆」的叙事型单页网站。

## 主题解读

汉语里只有一个词，同时指代两件截然不同的事：

- **机器的记忆（RAM）**——按 GB 报价，断电即失，无限复制。2026 年，它正被 AI 推着涨价：三大原厂把 70%–90% 的先进产能转向 HBM，消费级内存被系统性抽走。32GB DDR5 套条一年之内从约 ¥800 涨到 ¥3,400。
- **人的记忆**——无法扩容，无法备份，无法报价。约 2.5 PB，功耗 20 瓦，全世界仅此一份，没有备件。

于是有了这个标题的双关：**AI 让 RAM 变得更贵，爱让记忆变得更珍贵。** 同一个词的两端，价格走向完全相反——能被报价的那一端在变贵，不能被报价的那一端在变珍贵。

网站没有停在类比上，而是把这个双关做成了一个可以一路读下去的论证。

## 设计说明

**配色。** 三种语义色贯穿全站，互相不混用：

- 涨价红 `#cf2f1e`——一切与价格、上涨、AI 产能有关的数据
- 记忆金 `#a9781f`——一切与人的记忆、情感、不可定价有关的内容
- 硅片青 `#2b4553`——机器的参数与规格

背景是暖白纸张色，叠加一层 SVG 噪声做颗粒质感，整体是印刷品的调性而不是屏幕的调性。

**三个核心交互。** 都服务于论证，而不是装饰：

1. **同一个词开关**（Ch.01）——左右两张规格表参数一一对应，视觉上金色对青色，最后一行却一个是「无报价」、一个是「¥106/GB ↑」。切换动作本身就是在演示「同一个词，两个世界」。
2. **记忆估值器**（Ch.03）——先给一个真实成立的价格，再让你按「加上爱」，结果直接变成「不可定价」。数值先立后破。
3. **记忆标本馆**（Ch.05）——每张卡片都算出存储成本（¥26.50），但卡片上的标签是「存档 · 无替代品」，底部累计的是「情感溢价 ∞」。可计价的部分和不可计价的部分被并排放在同一行里。

**无障碍与克制。** 支持 `prefers-reduced-motion`（关闭全部动画与进场）、语义化标签、开关用 `role="switch"`、计算器结果区用 `aria-live`。所有长文数据都在 HTML 里硬编码，JS 只是增强；即使脚本加载失败，页面依然完整可读。

**自检。** 开发过程中用无头 Chrome 在 390 / 414 / 768 / 1024 / 1440 五个宽度下逐屏截图核对，并跑了一遍横向溢出诊断（`scrollWidth == clientWidth` 在全部宽度下成立）。
