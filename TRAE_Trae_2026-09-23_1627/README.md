# 记忆星图 · MEMORY ATLAS

> **爱让记忆变得更加珍贵 · AI has made RAM more expensive**
>
> 同一句双关，两种「记忆」的暗夜天文台。这是 TRAE 在不可参考其他子目录作品的前提下，对主题给出的独立作答。

## 项目介绍

一句话同时落在两本账上：中文读到的是情书——**爱**改写记忆的权重，让片段越被读取越珍贵；英文读到的是行情——**AI** 抢空产能，**RAM** 按 GB 计价、一路升值。

本站没有选择讲清楚道理，而是把两种「记忆」放进同一片夜空，让访客自己观测：

- **HERO**：九个汉字逐字点亮，「爱」呈玫瑰色、「记忆」呈金色；下方一道脉冲线在**心跳波形**与**上升行情线**之间周期性交替变形。
- **01 · 一字两读**：可拖拽（也可用键盘方向键）的分屏阅读装置，同一句话左读是玫瑰色的情书，右读是电光青的行情，中间用「爱 / AI、记忆 / RAM、珍贵 / EXPENSIVE」三组词对收束双关。
- **02 · 记忆星云**：可交互 Canvas 星图，18 颗光点分属两个族群——琥珀圆点是人类舍不得删的片段，青色方块是硅基中转瞬即逝的地址（L3 命中、ECC 校验位、未释放的张量……）。可拖动星图、点击光点读取双语卡片，并累计「已点亮」数量。
- **03 · 两条上升曲线**：滚动触发的双指数动画图表（DRAM 现货价格指数 vs AI 算力需求指数，2019=100，**主题示意数据**），标注「芯片短缺」「生成式 AI 爆发」「HBM 被包产」，以及一条玫瑰色的人类标注——「你翻到一个名字」。
- **04 · 记忆封存机**：核心交互。写下一段记忆（最多 60 字），它会被编码成闪烁的二进制流，随后点亮内存条（DIMM）上的一颗晶格、获得形如 `0xA3F90C21` 的十六进制地址，并盖上「珍」字玫瑰火漆印，标注**估值 · 无价 / NOT FOR SALE**。数据只写入访客浏览器的 `localStorage`，可随时「释放」。
- **05 · 尾声**：打字机逐字输出的双语诗句——「爱，是那个永不释放的进程。」

全站贯穿自定义双层光标、滚动进度、磁吸按钮、噪点暗角、流星划过、滚动入场等氛围特效，并适配移动端与 `prefers-reduced-motion`（自动降级为静态呈现）。

## 原理说明

**视觉系统。** 深色墨蓝夜空 `#07080D` 作为「观测场」，三色语义贯穿全站：玫瑰红 `#E26D7B` 代表「爱」、琥珀金 `#E9B44C` 代表「珍贵」、电光青 `#57C7E8` 代表「AI / 硅基记忆」。字体上用 Noto Serif SC 撑中文叙事、Cormorant Garamond 斜体承接英文诗意、Space Mono 处理地址与行情，形成「情书 / 行情」两套语感。

**三个 Canvas，各司其职：**

1. 全局星图（fixed 背景）：约 50–170 个按屏幕面积自适应的粒子，暖色系与青色系两个族群；暖色粒子近距离时自动牵线（记忆彼此牵连），偶发青色流星（硅基里逃逸的数据），并随鼠标产生景深视差。
2. HERO 脉冲线：用心电 PQRST 波形的高斯合成公式绘制心跳，每隔数秒切换为带锯齿、台阶和一次跳水的行情曲线，头部光点带辉光，实现「心跳 ⇄ 行情」的语义变形。
3. 记忆星云：18 个记忆节点独立漂移、同族连线，点击选中后高亮其社交邻接边并弹出双语读取卡片；支持拖拽整个星场（点击与拖动做了阈值区分）。

**图表。** 双指数曲线用 Canvas 手绘：Catmull-Rom 样条插值做平滑折线，滚动进入视口后用 2.2 秒描边动画 + 线性渐变面积填充；事件标注随描边进度逐条出现。所有数值均为主题示意，卡片中已明确标注。

**封存机。** 文本经 `TextEncoder` 计算字节数、FNV-1a 哈希生成十六进制地址；封存时先播放二进制流编码动画，再写入 `localStorage`（键 `memory-atlas-v1`），内存条 64 颗晶格按封存数量点亮，数据完全留在本机。

**无障碍与性能。** DPR 上限 2、星云离屏自动暂停、所有动画尊重 `prefers-reduced-motion`；分屏手柄支持键盘与 ARIA slider 属性，星云画布提供语义化 aria-label。
