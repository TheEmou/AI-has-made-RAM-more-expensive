# 爱让记忆变得更加珍贵 · AI has made RAM more expensive

一个纯静态的叙事型单页网站，围绕主题句「**爱让记忆变得更加珍贵 / AI has made RAM more expensive**」的一次自由发挥。

## 项目介绍

这句话是一个双关：中文里「爱（AI）」同音，「记忆」既是人的回忆、也是机器的 RAM，「珍贵 / expensive」一语两读。**同一个句子，人类读到情话，机器读到账单**——整站就建立在这条裂缝上。

页面共七个章节，一条从戏谑走向抒情的叙事线：

| 章节 | 内容 |
| --- | --- |
| 序 | 大标题 + 实时上涨的示意行情计数器 + 一根随滚动逐颗点亮的内存条 |
| 01 双关 | 「一句话，两套账本」，拨动开关在「人类读法 / 机器读法」之间切换整段文案 |
| 02 编年史 | 价格折线图 + 四个路口的时间轴（2023 AI 还在写诗 → 2026 你想起柜子里那根 DDR4） |
| 03 胃口 | 条形图对比「谁吃掉了内存」：训练集群 2.4 TB …… 一句「我记得你」0.000000012 GB |
| 04 典当行 | 交互估值器：写下一段回忆，按今日示意行情给出当票，并可下载保存 |
| 05 交换仪式 | 拉动滑块计算「换 16GB 需要交出多少段回忆」，SVG 天平随之倾斜 |
| 06 情书 | 打字机逐字呈现《给一根内存条的情书》 |

彩蛋：连按三次 `↑` 方向键，行情会额外跳涨一点。

- 支持 `prefers-reduced-motion`：开启后自动跳过动画直接呈现内容。

## 原理说明

- **零依赖**：不使用任何框架、图表库或 CDN。折线图、内存条、天平均为内联 SVG，条形图为纯 CSS，动画基于 CSS transition + 滚动驱动。
- **入场动画**：滚动驱动的 `getBoundingClientRect` 检测（而非 IntersectionObserver），元素顶边越过视口下缘即揭示；已滚过的内容也会补齐，避免锚点跳转时内容滞留不可见。
- **读法切换**：文案以 `data-h` / `data-m` 双份数据内联在 DOM 中，切换时先淡出、替换、再淡入，并给标题词一个错落的小跳动。
- **典当行估值**：`TextEncoder` 精确计字节数，按 `1GB = 1024³` 折算容量，乘以页内示意单价 ¥73.50/GB 得到估值；「可换回内存」刻意等于当品自身体积——一个循环论证，是整站的小小题眼。当票可导出为 UTF-8 文本文件。
- **示意数据**：页内所有价格、容量、用量、单价均为**虚构的叙事用数据**，页面多处显著标注，不构成任何真实行情参考。
