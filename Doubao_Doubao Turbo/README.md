# 爱让记忆变得更加珍贵 / AI has made RAM more expensive

> 一个关于「双关」的创意主题站。

## 项目介绍

「爱让记忆变得更加珍贵」与「AI has made RAM more expensive」——前者是情书，后者是行情，它们共用一个句子：

- **爱（ài）** 与 **AI** 同音；
- **记忆** 一词两义：既是心里放不下的往事（memories），也是内存条上按字节计价的存储（RAM / MEMORY）；
- **珍贵** 一体两面：被爱过的回忆「珍贵」，被 AI 抢产能的内存「珍贵（昂贵）」。

本站把这句话拆成两条叙事线交替展开：

| 区块 | 内容 |
| --- | --- |
| Hero | 双关解码：爱→AI、记忆→MEMORY、珍贵→PRECIOUS/EXPENSIVE |
| 双关拆解 | 「情书版」与「行情版」两枚卡片并置，附映射标签 |
| 行情 | ECharts 示意曲线：2024–2026 DRAM 现货价指数一路上行，标注 AI 抢产能、原厂涨价函等关键节点 |
| 记忆封存机 | 交互签名：输入一段记忆并「封存」，它获得一个十六进制地址，住进记忆条；估值随封存段数上涨（数据存于 localStorage） |
| 对照表 | 内存条参数 × 回忆参数的并排比较 |
| 载体史 | 时间轴：从口耳相传到大模型时代的记忆载体演进 |

## 运行方式

纯静态单页，无需构建、无需后端：

1. 直接双击 `index.html` 用浏览器打开即可（页面引用同目录 `assets/` 下的三张图片与 CDN 上的 ECharts，需要联网加载字体与图表库）。
2. 或在本目录起一个静态服务器：

   ```bash
   python -m http.server 8000
   ```

   然后访问 `http://localhost:8000`。

- 封存的记忆保存在浏览器 `localStorage` 中，键名为 `love_ram_vault_v1`，清空浏览器数据即消失。
- 移动端、桌面端均做了响应式适配；支持 `prefers-reduced-motion` 减弱动画。

## 原理说明

- **双关主题**：利用拼音同音（爱/AI）与英文一词两义（memory）构建立意，页面结构即围绕「两种读法」对称展开。
- **行情曲线**：使用 ECharts 折线图表达「趋势」，`markArea` 标注 AI 周期、`markPoint` 标注四个涨价关键节点；曲线数据为**示意数据**，仅用于主题表达，不构成任何事实陈述或投资建议。
- **记忆封存机**：纯前端交互。写入 → 生成随机十六进制内存地址 → 存入 localStorage → 渲染到 DIMM 记忆条网格（24 格）与最近记录列表；「估值 +3%/段」是对「记忆变贵」的拟物化表达。
- **载体史时间轴**：按「时间 / 轴 / 内容」三列网格实现，节点圆点由布局引擎居中，轴线像素级对齐。
- **视觉体系**：暖纸色（回忆/情书）与深色（芯片/行情）双面交替，衬线标题（Noto Serif SC）+ 无衬线正文 + 等宽数据字体（JetBrains Mono）三类角色；强调色取自同一色板（琥珀/青绿/绯红）。
- **图片素材**：三张氛围图（胶片×电路板、老照片、内存条特写）由图像生成模型产出，本地引用，路径为相对路径 `assets/`。
